Dia Gold ERP — Flow Video (Detailed Script)

Order 9002 ka poora flow · demo data · ~10–12 minute · har step: kya karna → kya dikhega → kya bolna
Order 9002 → Job Card (jobs 28860–62) → Job Mapping → Stones → Job History → MFG Transfer (TAG 361) → Ready Stock → Sale → WhatsApp → Payment
SHURU SE PEHLE (recording se pehle)
  1. Terminal me: python main.py --demo → login admin / admin.
  2. Window ke title me "DEMO DATA (testing)" dikhna chahiye. Window full screen kar lo.
  3. Saare purane tabs band (sirf Dashboard rahe).
  4. Screen recorder ON, mic ON. Ek baar 5 sec ki test recording kar lo — awaaz saaf aa rahi hai?
  5. Ye script doosri screen / phone pe khol lo.
GALTI SE BACHNA
  • Save aur Delete kabhi mat dabana. Hum sirf pehle se bane records khol ke dikha rahe hain.
  • Koi form khul jaaye to Cancel / Exit ya tab ka ×.
  • Mouse dheere chalao, har click ke baad 1–2 second ruko taaki video me dikhe.
  • Kuch atak jaaye to ghabrao mat — tab band karke wahi step dobara.
