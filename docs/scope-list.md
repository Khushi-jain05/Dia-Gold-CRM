# Dia Gold CRM — scope list: Built / Later / Drop (6 Oct)

Every legacy menu item, report and utility seen in the sessions of 3 Sept –
5 Oct, with where it stands. **Built** = in the app now. **Later** = waits for
your ranking (C-02) or your answer. **Drop?** = we propose not to build it;
tell us if you need it.

Please mark each "Later" line **W** (used weekly), **R** (rarely) or **N**
(never), and correct any "Drop?". That decides what we build next.
